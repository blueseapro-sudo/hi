# 부록. 약어 사전

강의에 나온 약어를 분야별로 모았습니다. "나온 곳"은 처음 또는 주로 나오는 강입니다.

## 1. AI 일반

| 약어 | 원어 | 쉬운 뜻 | 나온 곳 |
|---|---|---|---|
| AI | Artificial Intelligence | 인공지능. 사람처럼 배우고 판단하는 기계 | 1강 |
| AGI | Artificial General Intelligence | 범용 인공지능. 사람처럼 거의 모든 일을 하는 AI (아직 없음) | 2강 특이점 참고 |
| AX | AI Transformation | AI 전환. AI로 일하는 방식 자체를 바꾸는 것 | 안내, 활용편 |
| DX | Digital Transformation | 디지털 전환. AX의 앞 단계 | 참고 |
| GPU | Graphics Processing Unit | 그래픽 처리 장치. AI 학습에 쓰는 계산 장치 | 1강 |
| LLM | Large Language Model | 거대언어모델. 많은 글로 "다음 말"을 맞히며 배운 AI | 1강, 3강 |
| ML | Machine Learning | 머신러닝. 자료를 보고 스스로 규칙을 찾는 방식 | 1강 |
| DL | Deep Learning | 딥러닝. 신경망을 여러 층 쌓아 배우는 방식 | 1강 |

## 2. 모델·서비스 이름 속 약어

| 약어 | 원어 | 쉬운 뜻 | 나온 곳 |
|---|---|---|---|
| GPT | Generative Pre-trained Transformer | 미리 학습한 생성형 트랜스포머. OpenAI 모델 이름 | 1강, 3강 |
| GPT-4o의 o | omni | "모든 것". 글·그림·소리를 함께 다룬다는 뜻 | 3강 |
| LLaMA | Large Language Model Meta AI | Meta의 공개 언어모델 | 3강 |
| xAI | (회사 이름) | 일론 머스크가 세운 AI 회사. Grok 개발 | 3강 |
| 독파모 | 독자 AI 파운데이션 모델 | 정부의 국가대표 AI 모델 사업 | 3강 |
| UI | User Interface | 사용자 화면. GPT-6의 Intelligent UI | 3강 |

## 3. 에이전트·개발

| 약어 | 원어 | 쉬운 뜻 | 나온 곳 |
|---|---|---|---|
| MCP | Model Context Protocol | 에이전트를 외부 도구·데이터에 연결하는 표준 규격 | 5강 |
| API | Application Programming Interface | 프로그램끼리 주고받는 창구. API 키는 그 출입증 | 활용편 |
| CLI | Command Line Interface | 글자로 명령을 입력하는 화면(터미널). Claude Code가 동작하는 곳 | 4강 |
| npm | Node Package Manager | Node.js 프로그램 설치 도구 | 4강 |
| npx | (npm package executor) | 설치 없이 바로 실행하는 명령 | 5강 |
| JSON | JavaScript Object Notation | 설정을 적는 텍스트 형식. settings.json, .mcp.json | 4강, 5강 |
| md | Markdown | 마크다운. 기호로 제목·표를 적는 문서 형식. CLAUDE.md, SKILL.md | 4강, 5강 |
| jq | (명령 이름) | JSON에서 원하는 값만 꺼내는 도구. 훅 예시에 사용 | 5강 |
| rm / mv | remove / move | 삭제 / 이동 명령. 훅으로 막는 대상 | 5강 |
| DB | Database | 데이터베이스. 기록을 모아 두는 저장소 | 5강 |

## 4. 파일·데이터

| 약어 | 원어 | 쉬운 뜻 | 나온 곳 |
|---|---|---|---|

> [!tip] 약어를 AI에게 물을 때
> "MCP가 뭐야?"보다 "MCP를 소방서 공유폴더 예시로, 비전공자에게 3줄로 설명해줘"처럼 대상과 예시를 붙이면 바로 쓸 수 있는 설명이 나옵니다.
